-- vx.21 07.2026 monorepo. NO functional change against x.20 - this is the move into a
--        single source tree, released under its own number so the old and the new
--        binaries can be told apart in the field.
--        Repository: github.com/bontango/WillFA7
--          - ONE top/WillFA7.vhd for all five active boards instead of five copies.
--            Per board there is only variants/<name>/: variant_pkg.vhd (BOARD_ID,
--            ROM_COUNT, HAS_MONITOR), pins.tcl, device.tcl and WillFA7.sdc.
--          - ONE rtl/common/ instead of four copies of lib_common. Adding a module can
--            no longer be forgotten in six out of seven projects.
--          - The version lives in rtl/common/version_pkg.vhd, one number for all boards.
--            The x.19-shipped-as-x.18 kind of mismatch is now structurally impossible.
--          - WillFA7.qsf is generated by scripts/gen_qsf.ps1, not hand maintained.
--          - scripts/check.ps1 builds every variant with the right Quartus version and
--            compares logic elements, memory bits and slack against a baseline.
--        Two changes are behind the "no functional change" claim and deserve naming:
--          - Cyclone II used to carry its own cpu68 v0.83 and now uses the shared v0.85,
--            i.e. the DAA carry/negative flag fixes and the rewritten NMI handler that the
--            v4 board has been running in hardware since 03.2026. This also frees 56 logic
--            elements, taking the EP2C5 from 95 % down to 94 %.
--          - The optional ports LED_debug, USB_Tx, USB_Rx and debug are declared on every
--            board; where the pin does not exist the .qsf marks it VIRTUAL_PIN.
